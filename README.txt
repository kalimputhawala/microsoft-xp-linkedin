1. English
━━━━━━━━━━━━━━━━━━━━

A separate Chrome extension that gives LinkedIn a Windows XP appearance.

Features
- Windows XP Luna blue taskbar with a green Start button at the bottom-left.
- Start menu with Home, Network, Jobs, Messaging, Notifications, and your profile photo and link.
- LinkedIn’s original top header is hidden; search is available in the Start menu.
- The main layout uses the available screen width.
- LinkedIn’s native messaging interface gets the classic purple and cream Yahoo Messenger appearance.
- LinkedIn’s original messaging, posting, navigation, and chat controls remain available.

Installation or reinstallation
1. Open chrome://extensions in Chrome.
2. Turn Developer mode ON.
3. Click Load unpacked and select the linkedin-xp-theme folder.
4. Refresh the LinkedIn tab.

Extract the ZIP file first. Chrome loads the extension from the folder.

Keep the installed folder in Downloads. Moving or deleting it prevents the extension from loading.

To disable the extension, turn its switch OFF at chrome://extensions.

Privacy
- Works only on linkedin.com and www.linkedin.com.
- Uses no extension server, analytics, remote libraries, or background services.
- Does not read private message text or transmit it to external services.
- Uses your public profile link, name, and photo already displayed on the current page for the Start menu.
- Profile details are remembered only for the current tab’s session.

The extension may need updating if LinkedIn changes its page layout.

This is an independent personal theme, not an official Microsoft, Yahoo, or LinkedIn product.

2. العربية
━━━━━━━━━━━━━━━━━━━━

امتداد مستقل لمتصفح Chrome يغيّر مظهر LinkedIn.

الميزات
- شريط مهام أزرق بتصميم Windows XP Luna، مع زر «ابدأ» أخضر في أسفل اليسار.
- قائمة «ابدأ» تضم الصفحة الرئيسية (Home)، والشبكة (Network)، والوظائف (Jobs)، والرسائل (Messaging)، والإشعارات (Notifications)، بالإضافة إلى صورتك ورابط ملفك الشخصي.
- إخفاء الشريط العلوي الأصلي في LinkedIn، وإتاحة البحث من قائمة «ابدأ».
- يستفيد التصميم الرئيسي من عرض الشاشة المتاح.
- واجهة المراسلة الأصلية في LinkedIn بمظهر Yahoo Messenger الكلاسيكي، بألوانه البنفسجية والكريمية.
- تظل وظائف الرسائل والنشر والتنقل وأدوات الدردشة الأصلية في LinkedIn متاحة.

التثبيت أو إعادة التثبيت
1. افتح chrome://extensions في Chrome.
2. فعّل «وضع المطوّر» (Developer mode).
3. انقر على «تحميل إضافة غير مضغوطة» (Load unpacked)، ثم اختر مجلد linkedin-xp-theme.
4. أعد تحميل علامة تبويب LinkedIn.

فكّ ضغط ملف ZIP أولًا؛ إذ يحمّل Chrome الامتداد من المجلد.

احتفظ بالمجلد الذي ثبّتَّ الامتداد منه داخل مجلد التنزيلات (Downloads). نقله أو حذفه يمنع تحميل الامتداد.

لتعطيل الامتداد، أوقف تشغيله من chrome://extensions.

الخصوصية
- يعمل الامتداد فقط على linkedin.com وwww.linkedin.com.
- لا يستخدم خادمًا خاصًا بالامتداد، أو أدوات تحليلات، أو مكتبات تُحمّل عن بُعد، أو خدمات تعمل في الخلفية.
- لا يقرأ نصوص الرسائل الخاصة ولا يرسلها إلى خدمات خارجية.
- يستخدم رابط ملفك الشخصي العام واسمك وصورتك المتاحة في الصفحة الحالية لعرضها في قائمة «ابدأ».
- تُحفظ بيانات الملف الشخصي خلال جلسة علامة التبويب الحالية فقط.

قد يحتاج الامتداد إلى تحديث إذا تغيّر تصميم LinkedIn.

هذا مظهر شخصي مستقل، وليس منتجًا رسميًا من Microsoft أو Yahoo أو LinkedIn.

3. Türkçe
━━━━━━━━━━━━━━━━━━━━

LinkedIn’e Windows XP görünümü kazandıran bağımsız bir Chrome uzantısı.

Özellikler
- Windows XP Luna tarzında mavi görev çubuğu ve sol altta yeşil Başlat düğmesi.
- Ana Sayfa (Home), Ağım (Network), İş İlanları (Jobs), Mesajlaşma (Messaging) ve Bildirimler (Notifications) seçenekleriyle profil fotoğrafınızı ve profil bağlantınızı içeren Başlat menüsü.
- LinkedIn’in özgün üst çubuğu gizlenir; arama Başlat menüsünden yapılır.
- Ana düzen, ekranın kullanılabilir genişliğinden yararlanır.
- LinkedIn’in kendi mesajlaşma arayüzü, Yahoo Messenger’ın klasik mor ve krem renkli görünümüne kavuşur.
- LinkedIn’in özgün mesajlaşma, gönderi paylaşımı, gezinme ve sohbet kontrolleri kullanılabilir durumda kalır.

Kurulum veya yeniden kurulum
1. Chrome’da chrome://extensions adresini açın.
2. Geliştirici modunu (Developer mode) açın.
3. Paketlenmemiş öğe yükle (Load unpacked) düğmesine tıklayın ve linkedin-xp-theme klasörünü seçin.
4. LinkedIn sekmesini yenileyin.

Önce ZIP dosyasını çıkarın. Chrome uzantıyı klasörden yükler.

Uzantıyı yüklediğiniz klasörü İndirilenler (Downloads) klasöründe tutun. Klasörü taşımak veya silmek, uzantının yüklenmesini engeller.

Uzantıyı devre dışı bırakmak için chrome://extensions sayfasındaki anahtarını kapatın.

Gizlilik
- Yalnızca linkedin.com ve www.linkedin.com üzerinde çalışır.
- Uzantıya ait bir sunucu, analiz araçları, uzaktan yüklenen kütüphaneler veya arka plan hizmetleri kullanmaz.
- Özel mesaj metinlerini okumaz veya harici hizmetlere iletmez.
- Başlat menüsü için mevcut sayfada görüntülenen, size ait herkese açık profil bağlantısını, adınızı ve fotoğrafınızı kullanır.
- Profil bilgileri yalnızca mevcut sekme oturumu boyunca hatırlanır.

LinkedIn’in sayfa düzeni değiştiğinde uzantının güncellenmesi gerekebilir.

Bu, bağımsız bir kişisel temadır; Microsoft, Yahoo veya LinkedIn’in resmî ürünü değildir.
